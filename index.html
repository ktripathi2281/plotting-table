    drwxr-xr-x tollgate/ LLM gateway in Go in progress

    An OpenAI-compatible LLM gateway in Go with payments-grade spend control. Point any OpenAI SDK at it: it checks a virtual key, enforces its rate limits and budget, routes the call with retries and fallback, streams the answer and records what it cost.

    client · any OpenAI SDK
   │  POST /v1/chat/completions
   ▼
virtual key ─► rate limits ─► idempotency
                                  │
   ┌──────────────────────────────┘
   ▼
hold the worst case, in micro-USD
   │
   ▼
router ─► OpenAI-compatible · Anthropic
   │      retries, fallback, breakers
   ▼
settle the actual cost, store, respond

    stack Go, PostgreSQL (pgx, sqlc), Prometheus, Docker · OpenAI-compatible and Anthropic APIs on raw net/http

    • Done: OpenAI-compatible and Anthropic adapters, with retries, fallback and a circuit breaker per target, and streaming with a commit point.
    • Done: hold-and-settle budgets in integer micro-USD, idempotency keys and reconciliation. 200 concurrent requests against a budget that fits exactly 37 holds: exactly 37 succeed.
    • Benchmarked against a mock upstream: about 1.5 ms of overhead at the median. Next: a run with a live provider key, then a hosted demo.
